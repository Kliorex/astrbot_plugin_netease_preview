# 网易云点歌预览

这是一个 AstrBot 4.x 插件。用户发送点歌指令后，插件通过网易云公开 Web 接口搜索歌曲，选择首个当前可播放的候选项，截取数秒音频并转换为 AstrBot 支持的 WAV 语音消息。

## 安装

将整个 `astrbot_plugin_netease_preview` 目录放入 AstrBot 的 `data/plugins/`，然后在 WebUI 插件管理中重载插件。AstrBot 会根据 `requirements.txt` 安装 `aiohttp` 和带 ffmpeg 可执行文件的 `imageio-ffmpeg`。

Docker 部署时，典型目录是：

```text
/AstrBot/data/plugins/astrbot_plugin_netease_preview
```

## 使用

```text
点歌 晴天 周杰伦
网易云点歌 海阔天空
music 夜曲
点歌 https://music.163.com/song?id=歌曲ID
```

指令不需要添加 `/`。也可以直接提供纯数字歌曲 ID。插件先发送歌曲信息，再发送一条 WAV 语音。

## 配置

- `语音预览时长`：默认 8 秒，可设置为 3-15 秒。
- `网易云 MUSIC_U 登录凭证`：选填。配置后插件会验证账号，并使用该账号已有的会员和已购权限获取音源。
- `预览起始位置`：默认从第 30 秒开始，歌曲长度不足时自动向前调整。
- `搜索候选数量`：默认检查前 5 个结果，跳过没有可用音源的歌曲。
- `网易云请求超时`、`音频转换超时`：限制网络请求和 ffmpeg 运行时间。
- `自定义 ffmpeg 路径`：通常留空；仅在希望使用系统 ffmpeg 时填写。

## 限制

- 插件使用网易云未公开承诺稳定性的 Web 接口，接口变更、风控、地区和版权限制都可能导致部分歌曲无法预览。
- 插件不会绕过登录、付费或版权限制；接口未返回音源时会提示失败。
- `MUSIC_U` 可在已登录网易云网页版的浏览器 Cookie 中找到。可以只填写值，也可以填写 `MUSIC_U=...`，修改后需要重载插件。该凭证等同登录凭据，请勿发送给他人或提交到公开仓库。
- 本地 WAV 临时文件在消息发送完成后立即删除，不会缓存完整歌曲。
- 语音消息的最终支持情况取决于所使用的平台适配器。元数据默认声明 QQ OneBot 和 QQ 官方适配器。
